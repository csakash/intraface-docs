The `intraface` CLI pulls a board into a folder, previews it and publishes your changes. It needs Node.js 22 or newer; `npx intraface@latest <command>` runs the latest version without installing anything.

Every command prints one JSON document on stdout with `--json`: `{ "ok": true, … }` or `{ "ok": false, "error": { "code", "message", "hint" } }`.
